# Coverage tooling

- `overview.py` (core): both coverage figures split by the layer of test that runs each line, the
  README's badges and the Python ratchet.
- `code_map.py` (testing showcase): which tests run each module, public function and site file, for
  the wiki's code map.
- `mutation.py`, `mutation-equivalent.toml` (testing showcase): mutation testing of the engine, and
  the changes that behave the same as the code, each with its reason.

The testing showcase is the maintainer's testing portfolio and asks nothing of contributors (wiki:
"Testing showcase").
